# Contributing to NeurisAI Core

Thank you for your interest in contributing to NeurisAI.

## Development Setup

1. Fork the repository
2. Create a feature branch from `main`
3. Set up your development environment (see README)
4. Make your changes
5. Run the test suite: `pytest tests/ -v`
6. Run the linter: `ruff check .`
7. Submit a pull request

## Code Standards

- All code must pass type checking with `mypy --strict`
- Test coverage must not decrease
- Follow existing patterns in the codebase
- Document any new public APIs

## Research Contributions

If your contribution involves new behavioral models or psychological assessment methods, please include references to peer-reviewed literature supporting the approach.

## Security

If you discover a security vulnerability, please report it privately to security@neurisai.me rather than opening a public issue.
